## About The Project

His Image Apparel is a fully responsive, interactive e-commerce front-end built to showcase and sell Christian-themed clothing. The site combines modern design principles with a clear purpose: enabling believers to express their faith through apparel.

> "So whether you eat or drink or whatever you do, do it all for the glory of God." — 1 Corinthians 10:31

### Features

- **Product Catalog** — Browse tees, caps, hoodies, and sweaters
- **Category Filtering** — Instantly filter products by category
- **Shopping Cart** — Fully functional cart with persistent storage via `localStorage`
- **Dark Mode** — Toggle between light and dark themes with saved preference
- **Daily Encouragement** — Click the floating cross to receive a random Bible verse
- **Fully Responsive** — Optimized for mobile, tablet, and desktop devices
- **Add-to-Cart Notifications** — Visual feedback when items are added to the cart
- **Accessibility** — ARIA labels, semantic HTML, and keyboard-friendly navigation

## Built With

- **HTML5** — Semantic document structure
- **CSS3** — Custom styling, animations, and responsive design
- **Vanilla JavaScript** — No frameworks or external dependencies
- **[Google Fonts](https://fonts.google.com/)** — Montserrat and Playfair Display
- **[Font Awesome](https://fontawesome.com/)** — Iconography
- **localStorage API** — Cart and theme preference persistence
